# Entregable 5 - Sitio Web Personal

## Descripción

Este proyecto corresponde al Entregable 5 del curso de Desarrollo Web.

Se trata de un sitio web personal desarrollado para presentar información sobre mi perfil profesional, habilidades, proyectos y medios de contacto.

El proyecto incorpora HTML5 y CSS3 junto con el framework Bootstrap para mejorar la estructura, el diseño y la experiencia de navegación.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5.3
- Google Fonts
- Git
- GitHub

## Características

El sitio web cuenta con las siguientes secciones:

- Inicio
- Sobre mí
- Proyectos
- Habilidades
- Contacto

También incluye:

- Barra de navegación responsive.
- Diseño adaptable a diferentes tamaños de pantalla.
- Carrusel de imágenes utilizando Bootstrap.
- Tarjetas para presentar proyectos.
- Distribución de contenido mediante Flexbox y CSS Grid.
- Efectos `hover`.
- Variables CSS para administrar los colores del sitio.
- Diseño responsive mediante Media Queries.
- Imágenes y contenido relacionado con desarrollo web y tecnología.
